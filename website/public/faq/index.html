About Publisher files

Why convert my Publisher files now?

Microsoft ended support for Publisher in October 2026, and Microsoft 365 subscribers can no longer open .pub files in it. Microsoft recommends converting them to PDF or Word. PDF is the safest long-term format because it looks the same everywhere. Read more.

Do I need Microsoft Publisher installed?

No. PubConv reads .pub files itself and includes everything it needs. It's made for people who no longer have Publisher.

Which Publisher versions are supported?

Files from Publisher 2000 onward, with the best results from Publisher 2007 and later. Very old files (Publisher 95 to 98) may convert with reduced fidelity. The free trial is the quickest way to check your own archive.

Can PubConv convert to Word instead of PDF?

Not at the moment. PubConv creates PDFs, the format Microsoft recommends for keeping layouts intact. Publisher layouts rarely survive conversion to Word without manual tidying. PDF or Word?

Quality

Will my PDFs look exactly like Publisher?

Very close for most documents, and much closer than other converters for WordArt and newsletters. Known gaps: rainbow or multi-colour WordArt gradients and 3D WordArt effects are drawn in a single colour. Try the free trial on your own files to see.

What does PubConv do better than free converters?

Free converters often drop or garble WordArt headlines, and print newsletter articles twice when text flows between linked boxes. PubConv reads those parts of the file properly and flows newsletter text the way Publisher does. See our test.

Can I search and copy text in the PDFs?

Yes. Text in your documents, including WordArt headlines and newsletter articles, stays searchable and copyable in the PDF, so archives remain easy to find things in.

What about fonts?

PubConv uses the fonts installed on your PC. For the closest match, install the fonts your documents use. Missing fonts are replaced with similar ones.

Privacy and security

Are my files uploaded anywhere?

No. Everything happens on your computer. PubConv doesn't need an internet connection and doesn't collect any data about you or your files.

Windows says "Windows protected your PC". Is it safe?

Windows shows this for new software from smaller publishers it doesn't recognise yet. Click "More info" and then "Run anyway". If you'd rather avoid the message, install PubConv from the Microsoft Store, where Microsoft checks and signs it.

Does PubConv change my original files?

Never. It only reads them and writes new PDF files.

Using PubConv

Can it convert a whole folder at once?

Yes. Add a folder (subfolders included) or drag several folders onto the window. Each file gets its own PDF and a result in the list.

Is there a command line for IT teams?

Yes. pubconv-cli "D:\Archive" -r -o "D:\PDF" converts a whole tree and returns exit code 0 when every file converted. Bulk conversion guide.

Does it work on Mac?

Not yet. PubConv runs on Windows 10 and 11.
